# 港口集装箱作业管理平台

面向港口集装箱码头船舶靠离泊、岸桥装卸、堆场翻倒、闸口进出与危险品申报的一体化作业管理后台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 拖轮派工口径

拖轮调度的马力口径只有一份：`backend/app/services/tug_rules.py`。拖轮台账、派工单、
调度看板以及前端页面读到的「所需马力」都由它计算，前端不自行算马力，全部调后端接口。

- **所需马力**：按「水域 × 船型」分开配置单位马力系数、马力下限、最少条数与允许时段；
  `所需马力 = max(ceil(作业量 × 单位马力系数), 马力下限)`，
  `建议条数 = max(ceil(所需马力 / 单条折算马力), 最少条数)`。
  作业量口径随船型而定（集装箱船按 TEU 作业箱量，散货船/油轮按千载重吨，件杂货/客滚按千总吨）。
- **检修不派工**：检修中（及停用）的拖轮不参与派工，派工接口直接拒绝；执行中的拖轮不能登记检修。
- **撞车以先落库为准**：同一拖轮作业窗口重叠时，后一次登记直接作废并提示先落库的那张派工单；
  端点相接不算冲突。派工登记串行化，并发抢同一条船时一存一拒。
- **马力不足拦截**：所选拖轮合计马力低于所需马力（或条数低于最少条数）时不允许派工，
  返回里说明还差多少马力。
- **超窗口提示**：作业窗口超出该水域允许时段时照常落库，但在 `warnings`、派工单「提示」列
  与看板「超窗口提示」里另行标注，不算作硬拦截。
- **同作业只留最新版**：同一作业编号重复登记按覆盖处理，不新增派工单。

主要接口（前缀 `/api/tug`）：

| 接口 | 说明 |
| --- | --- |
| `GET /board` | 调度看板：分水域待命条数/可用马力、在执派工单、超窗口提示 |
| `GET /standards` | 分水域派工口径配置 |
| `GET /calculate?area=&vessel_type=&workload=` | 马力试算，只返回所需马力与建议条数，不落库 |
| `GET /tugs` / `POST /tugs/{id}/actions` | 拖轮台账与检修/归队动作 |
| `GET /orders` / `POST /orders` | 派工单列表与登记（含拦截与提示） |
| `POST /orders/{id}/actions` | 完成作业 / 取消派工，并释放仍未占用的拖轮 |
